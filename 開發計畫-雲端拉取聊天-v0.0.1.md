# 雲端拉取聊天（新裝置 / 無 chat_id）開發計畫 v0.0.1

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 當本地沒有某個聊天（沒有 chat_id）、但雲端有備份時，使用者可從面板瀏覽 `SillyTavernSync/` 的角色與聊天清單，選定後把聊天拉到本地建檔、開啟、續聊，且後續上傳仍回到同一個雲端資料夾（chat_id 連續）。

**Architecture:** 維持現行「chat_id ＝ 聊天檔名時間戳」識別模型（[src/chat/meta.ts](src/chat/meta.ts)、tasks/phase-4、phase-5 已定案此模型；[開發手冊-v2.md](開發手冊-v2.md) §4.1 的 UUID 敘述屬過時稿，由 Task 7 更正）。拉取時**不走酒館匯入端點**（匯入會改檔名、導致 chat_id 分岔），改用 `/api/chats/save` 以 `{角色名} - {chat_id}` 為檔名直接建檔（[src/tavern.ts:273](src/tavern.ts:273) 的 `replaceRawChat` 已驗證此端點可行），再以 `openCharacterChat` 開啟——檔名決定 chat_id，因此拉下來的聊天自動指回同一個雲端資料夾。角色卡缺失時先從該聊天的 `character/` 備份還原（`createOrReplaceCharacter` 已在 [src/tavern.ts:202](src/tavern.ts:202) 實作）。

**Tech Stack:** TypeScript（strict）、vitest、webpack、pnpm；Google Drive REST v3（經現有 `DriveClient` 抽象）；SillyTavern context API（`openCharacterChat`、`selectCharacterById`）與 `/api/chats/save`、`/api/characters/chats` 端點。

## Global Constraints

- 不新增任何 npm 依賴。
- 所有 Drive 存取一律經 `DriveClient` 介面（`GoogleDriveClient` / `MemoryDriveClient` 同步實作），單元測試不得打網路。
- UI 控件沿用酒館標準 class（`menu_button`、`text_pole`、`checkbox_label`），顏色吃 `--SmartTheme*` 變數附 fallback（手冊 14.1）。
- 使用者可見文案一律繁體中文。
- 未連線 Drive 時拉取入口按鈕須 disable（手冊 14.4 防呆）。
- 每個 task 結束執行 `pnpm verify`（lint + typecheck + test + build）必須全綠。
- Drive 目錄結構不變：`SillyTavernSync/{role_key}/{chat_id}/{chat|character|...}`；`_pre_restore`、`_self_check` 為功能性資料夾，瀏覽清單不得列出。
- **版控注意**：本專案目前不是 git repo。開工前先 `git init && git add -A && git commit -m "chore: baseline before cloud-pull feature"`；若團隊不使用 git，將各 task 的 commit 步驟替換為「`pnpm verify` 全綠」檢查點。

## 為什麼不改回手冊 §4.1 的 UUID 模型（決策記錄）

- 實作與 phase-4 / phase-5 任務文件均已採「chat_id ＝ 檔名時間戳」，Phase 0–2 測試皆建立在此模型上；改 UUID 需重寫 meta 邏輯與大量測試，並失去現有「檔名不一致即重綁」對酒館分支/複製聊天（chat 變數會被複製）的防護。
- 檔名模型下，只要拉取時以 chat_id 命名建檔，`deriveChatId(新檔名) === chat_id`，[src/chat/meta.ts:17](src/chat/meta.ts:17) 的重綁條件不成立，身分自然連續——問題根源（匯入改名）用「不走匯入、自己指定檔名」繞開。
- 已知限制（寫入手冊）：使用者手動重新命名聊天檔會使 chat_id 分岔，形同開新窗。

```ts
import type { DriveVersion } from '../drive/DriveClient';
import type { DriveService } from '../drive/DriveService';

export type CloudRoleEntry = {
  roleKey: string;
};

export type CloudChatEntry = {
  chatId: string;
  versionCount: number;
  latest: DriveVersion | null;
};

const ROOT_FOLDER = 'SillyTavernSync';
// 非聊天資料的功能性資料夾，瀏覽清單不列出
const EXCLUDED_FOLDERS = new Set(['_pre_restore', '_self_check']);

export async function listCloudRoles(drive: DriveService): Promise<CloudRoleEntry[]> {
  const folders = await drive.listChildFolders([ROOT_FOLDER]);
  const names = [...new Set(folders.map(folder => folder.name))].filter(name => !EXCLUDED_FOLDERS.has(name));
  return names.map(roleKey => ({ roleKey }));
}

export async function listCloudChats(drive: DriveService, roleKey: string): Promise<CloudChatEntry[]> {
  const folders = await drive.listChildFolders([ROOT_FOLDER, roleKey]);
  const chatIds = [...new Set(folders.map(folder => folder.name))].filter(name => !EXCLUDED_FOLDERS.has(name));
  const entries = await Promise.all(
    chatIds.map(async chatId => {
      const versions = await drive.listVersions([ROOT_FOLDER, roleKey, chatId, 'chat']);
      return { chatId, versionCount: versions.length, latest: versions.at(-1) ?? null } satisfies CloudChatEntry;
    })
  );
  // 最新更新的窗排前面；沒版本的排最後
  return entries.sort((left, right) => (right.latest?.filename ?? '').localeCompare(left.latest?.filename ?? ''));
}
```

```ts
export function createTavernPullAdapter(): TavernPullAdapter {
  const globals = globalThis as Record<string, any>;

  return {
    listCharacterNames() {
      const context = getSillyTavernContext();
      if (!Array.isArray(context?.characters)) {
        return [];
      }
      return context.characters
        .map((character: Record<string, unknown>) => character?.name)
        .filter((name: unknown): name is string => typeof name === 'string' && name.length > 0);
    },
    async selectCharacterByName(name) {
      const context = getSillyTavernContext();
      if (!Array.isArray(context?.characters) || typeof context?.selectCharacterById !== 'function') {
        throw new Error('酒館 selectCharacterById API 不可用');
      }
      const index = context.characters.findIndex((character: Record<string, unknown>) => character?.name === name);
      if (index < 0) {
        throw new Error(`本地找不到角色卡：${name}`);
      }
      await context.selectCharacterById(index);
    },
    getCurrentCharacterName() {
      const context = getSillyTavernContext();
      const globalName =
        typeof globals.getCurrentCharacterName === 'function' ? globals.getCurrentCharacterName() : null;
      return globalName ?? readOptionalString(context?.name2) ?? null;
    },
    async listCurrentCharacterChatFiles() {
      const avatarUrl = getCurrentCharacterAvatarUrl();
      const response = await fetch('/api/characters/chats', {
        method: 'POST',
        headers: getRequestHeaders(),
        body: JSON.stringify({ avatar_url: avatarUrl, simple: true }),
        cache: 'no-cache'
      });
      if (!response.ok) {
        throw new Error(`SillyTavern 聊天清單讀取失敗: ${response.status}`);
      }
      const result = (await response.json()) as unknown;
      const rows = Array.isArray(result) ? result : Object.values(result as Record<string, unknown>);
      return rows
        .map(row => readOptionalString((row as Record<string, unknown>)?.file_name))
        .filter((name): name is string => Boolean(name));
    },
    async createAndOpenChatFile(fileName, rawJsonl) {
      const context = getSillyTavernContext();
      // 開啟能力先探測：save 之後才發現開不了會留下孤兒檔
      if (typeof context?.openCharacterChat !== 'function') {
        throw new Error('酒館 openCharacterChat API 不可用，無法開啟拉取的聊天');
      }
      const avatarUrl = getCurrentCharacterAvatarUrl();
      const response = await fetch('/api/chats/save', {
        method: 'POST',
        headers: getRequestHeaders(),
        body: JSON.stringify({
          avatar_url: avatarUrl,
          file_name: fileName,
          chat: parseRawChatMessages(rawJsonl),
          force: true
        }),
        cache: 'no-cache'
      });
      if (!response.ok) {
        throw new Error(`SillyTavern 聊天檔建立失敗: ${response.status}`);
      }
      await context.openCharacterChat(fileName);
    },
    async applyCharacter(snapshot) {
      if (typeof globals.createOrReplaceCharacter !== 'function') {
        throw new Error('Character restore API is unavailable');
      }
      const targetName = snapshot.characterName ?? 'Imported Character';
      await globals.createOrReplaceCharacter(targetName, snapshot.data, { render: 'none' });
    },
    writeChatMeta(meta) {
      if (typeof globals.insertOrAssignVariables !== 'function') {
        throw new Error('酒館助手 chat 變數 API 不可用');
      }
      globals.insertOrAssignVariables({ [CHAT_META_KEY]: meta }, { type: 'chat' });
    }
  };
}

function getCurrentCharacterAvatarUrl(): string {
  const context = getSillyTavernContext();
  const characterId = readOptionalString(context?.characterId);
  const characterIndex = characterId === undefined ? Number.NaN : Number(characterId);
  const character =
    Array.isArray(context?.characters) && Number.isInteger(characterIndex) ? context.characters[characterIndex] : null;
  const avatarUrl = readOptionalString(character?.avatar);
  if (!avatarUrl) {
    throw new Error('無法取得目前角色的 avatar');
  }
  return avatarUrl;
}
```

```ts
import { sanitizeRoleKey } from '../roleKey';
import type { DriveService } from '../drive/DriveService';
import { loadSettings } from '../settings';
import { countJsonlMessages } from './ChatSyncService';
import { buildPulledChatFileName, deriveChatId } from './meta';

const ROOT_FOLDER = 'SillyTavernSync';

export type PullResult = {
  filename: string;
  chatFileName: string;
  characterRestored: boolean;
};

export function chatFileMatchesChatId(fileName: string, chatId: string): boolean {
  if (deriveChatId(fileName) === chatId) {
    return true;
  }
  const stem = fileName.replace(/\.[^.]+$/, '');
  return stem === chatId || stem.endsWith(` - ${chatId}`);
}

export class ChatPullService {
  constructor(
    private tavern: TavernPullAdapter,
    private drive: DriveService
  ) {}

  async pullChat(roleKey: string, chatId: string): Promise<PullResult> {
    const characterRestored = await this.ensureCharacter(roleKey, chatId);

    const localChatFiles = await this.tavern.listCurrentCharacterChatFiles();
    if (localChatFiles.some(fileName => chatFileMatchesChatId(fileName, chatId))) {
      throw new Error('本地已存在這個聊天（chat_id 相同）。請切到該聊天後改用「下載並覆蓋」。');
    }

    const versions = await this.drive.listVersions([ROOT_FOLDER, roleKey, chatId, 'chat']);
    const latest = [...versions].reverse().find(version => version.filename.endsWith('.jsonl'));
    if (!latest) {
      throw new Error('這個聊天在雲端沒有可拉取的原始（.jsonl）版本');
    }
    const content = await this.drive.downloadText(latest.fileId);

    const characterName = this.tavern.getCurrentCharacterName() ?? roleKey;
    const chatFileName = buildPulledChatFileName(characterName, chatId);
    await this.tavern.createAndOpenChatFile(chatFileName, content);

    // 校正 meta：身分沿用雲端，last_synced_version 設為剛拉取的版本
    this.tavern.writeChatMeta({
      chat_id: chatId,
      role_key: roleKey,
      device_name: loadSettings().deviceName,
      last_synced_version: latest.filename,
      last_synced_message_count: countJsonlMessages(content)
    });

    return { filename: latest.filename, chatFileName, characterRestored };
  }

  private async ensureCharacter(roleKey: string, chatId: string): Promise<boolean> {
    const matched = this.findLocalCharacterName(roleKey);
    if (matched) {
      await this.tavern.selectCharacterByName(matched);
      return false;
    }

    const versions = await this.drive.listVersions([ROOT_FOLDER, roleKey, chatId, 'character']);
    const latest = versions.at(-1);
    if (!latest) {
      throw new Error(
        `本地沒有角色卡「${roleKey}」，且雲端沒有這個聊天的角色卡備份。請先手動安裝角色卡，或在來源裝置執行「備份完整環境」。`
      );
    }
    const snapshot = await this.drive.downloadJson<CharacterSnapshot>(latest.fileId);
    await this.tavern.applyCharacter(snapshot);
    const restored = this.findLocalCharacterName(roleKey) ?? snapshot.characterName;
    if (!restored) {
      throw new Error('角色卡還原後仍找不到對應角色，請重新整理頁面後再試');
    }
    await this.tavern.selectCharacterByName(restored);
    return true;
  }

  private findLocalCharacterName(roleKey: string): string | null {
    return (
      this.tavern.listCharacterNames().find(name => name === roleKey || sanitizeRoleKey(name) === roleKey) ?? null
    );
  }
}
```

```ts
        return;
```
