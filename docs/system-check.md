# 系統檢查使用說明

TavernRoamer 的設定頁提供「快速檢查」與「進階診斷」。一般排錯先執行快速檢查即可。

## 快速檢查會做什麼

- 唯讀檢查設定、目前聊天、環境備份／還原能力、從雲端建立聊天與自動同步前置條件。
- 實際呼叫聊天匯出與目前角色聊天清單等唯讀端點。
- 若已連線 Google Drive，會在 `SillyTavernSync/_self_check/<run_id>` 建立一個暫存檔，驗證上傳、列舉與下載後立即刪除檔案及該次 run folder。

快速檢查不會修改 `_drive_sync`、聊天訊息、角色卡、世界書、Persona、Preset 或 Regex。

若 Drive 清理失敗，結果會列出暫存路徑。可前往 Google Drive，依報告路徑手動刪除殘留資料。

## 進階診斷

進階診斷只應在專用測試角色與測試聊天上執行，啟動前會再次確認。

- 角色卡來回：建立帶有 `TavernRoamer SelfCheck` 名稱的暫存角色卡，驗證後刪除。
- 聊天覆寫來回：短暫修改目前測試聊天，再以執行前保存的完整 package 還原。此案例要求先停用自動同步。

如果無法安全清理暫存資料，對應進階案例會顯示「不適用」而不執行。

## 結果狀態

| 狀態 | 意義 | 是否需要處理 |
|---|---|---|
| 通過 | 功能與前置條件正常 | 否 |
| 需處理 | API、資料格式、網路或清理失敗 | 是 |
| 待完成 | 尚未連線、未選角色或未開啟聊天 | 先完成畫面提供的前置步驟 |
| 不適用 | 功能停用，或為保護資料而不執行 | 通常不需要 |

## 複製診斷報告

完成後可按「複製診斷報告」。報告包含案例 ID、分類、時間、耗時、origin 與技術 details；access token 和完整 Google Client ID 會自動遮蔽。分享前仍建議快速檢查內容是否包含不想公開的角色、聊天檔或世界書名稱。
