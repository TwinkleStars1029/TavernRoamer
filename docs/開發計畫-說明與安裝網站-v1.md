# TavernRoamer 說明與安裝網站開發計畫 v1

日期：2026-09-28  
狀態：開發前計畫；本文件不代表網站已實作或發布。

## 1. 目標與產品主軸

建立繁體中文網站，讓第一次接觸 TavernRoamer 的 SillyTavern 使用者能理解用途、完成安裝與 Google OAuth 設定，並成功在另一台裝置接續聊天。

首頁主軸：

> 讓你的酒館聊天，跟著你走。
> 將 SillyTavern 聊天與相關素材備份到自己的 Google Drive，在另一台裝置接續故事。

主要入口為「開始安裝」，次要入口為「查看使用流程」。網站必須明確說明 TavernRoamer 是酒館助手／JS-Slash-Runner 腳本，需要既有 SillyTavern 與酒館助手。

### 成功標準

- 新使用者能說出聊天同步與環境備份的差別。
- 使用者不必閱讀原始碼，即可完成腳本安裝及自建 Google OAuth 設定。
- 使用者能在來源裝置完成備份，並在另一台裝置找到、拉取聊天。
- 發生連線問題時，能依錯誤訊息找到相應排解步驟。
- 官網描述與實際發布版本一致，安裝入口提供可用且已驗證的產物。

## 5. Google OAuth 申請與設定指南

這是第一版的核心內容，不能用「自行申請 Client ID」一句帶過。

### 5.1 完整步驟

| 步驟 | 教學內容 | 完成證據 |
|---|---|---|
| 1. 建立專案 | Google Cloud Console 入口、新建／選取專案、確認目前專案 | 專案名稱可辨識 |
| 2. 啟用 API | 找到 Google Drive API 並啟用 | 該 API 顯示已啟用 |
| 3. 同意畫面 | 依目前 Google Auth Platform 介面說明 Branding、Audience、聯絡資訊 | 必填資訊完成 |
| 4. 使用者與狀態 | 自用情境的 External／Testing 設定、加入測試帳號；補充組織帳號例外 | 實際授權帳號符合設定 |
| 5. 存取權限 | Data Access 中核對 `https://www.googleapis.com/auth/drive.file` | 權限與程式要求一致 |
| 6. OAuth Client | Clients 中建立 Web application、填入 Authorized JavaScript origins | Client ID 已建立 |
| 7. 回填腳本 | TavernRoamer 設定 → Google Client ID → 儲存設定 → 連線 Google Drive | 面板顯示已連線 |
| 8. 另一台裝置 | 使用相同 Cloud 專案／Client ID 與同一 Drive 帳號，登錄該裝置來源並各自授權 | 可找到來源裝置的備份 |

教學說明建立 OAuth Client 與申請發布審核的差別。Testing 的限制、授權有效期與正式發布需求在製作時依 Google 官方文件確認，不承諾所有情境免審核或永久授權。

目前程式採 Google Identity Services 瀏覽器 token flow；教學必須與此流程一致，不引導使用者把 Client Secret 貼進脚本，也不加入與本流程無關的 redirect URI 設定。

### 5.2 酒館網址格式助手

- 輸入使用者實際開啟的酒館網址，輸出 `URL.origin` 及一鍵複製按鈕。
- 明確說明要填「酒館網址的來源」，不是說明網站的網址。
- 路徑、query、fragment 不進入 origin；保留必要的 scheme、host、port。
- `localhost` 與 `127.0.0.1` 分別顯示，不能自動視為同一來源。
- 允許整理多筆網址並去重，用於本機、另一台裝置、雲端酒館。
- 拒絕非 HTTP(S)、含帳密、無法解析的輸入；對非本機 HTTP 顯示需核對 Google 允許規則的提示。
- 不默默補上 scheme；缺少 `http://` 或 `https://` 時要求補齊並給範例。
- 輸入與轉換在瀏覽器內完成，不上傳或持久保存網址。
- 說明格式正確不代表 Google 已接受，也不代表連線已成功。

示例：`http://127.0.0.1:8000/` → `http://127.0.0.1:8000`；`https://tavern.example.com/path?x=1` → `https://tavern.example.com`。範例使用假資料，不公開目前專案使用者的私人部署地址。

### 5.3 權限說明

以一般使用者能理解的文字解釋 `drive.file` 存取 app 建立或獲使用者授權的特定檔案；不將其描述成可讀取整個 Drive。手動放入同名資料夾的檔案，不一定能被脚本讀到。[Google Drive 官方 scope 說明](https://developers.google.com/workspace/drive/api/guides/api-specific-auth)

OAuth 頁面附官方文件入口與最後核對日期，並在 Google 介面變更時更新截圖。[Google Client 設定文件](https://developers.google.com/identity/gsi/web/guides/get-google-api-clientid)、[JavaScript origin 規則](https://developers.google.com/identity/protocols/oauth2/javascript-implicit-flow)

- [ ] 環境內容依目前實作列出：角色卡、世界書、Persona、Preset、Regex；各類詳細範圍與綁定行為需實測。
- [ ] 說明還原預覽、覆蓋前備份、全域素材可能影響其他聊天，以及失敗後的處理方式。
- [ ] 核對群組聊天、聊天改名、同時編輯、版本保留、Quick Reply、API 設定等邊界，分為已支援／未支援／尚未驗證。
- [ ] 以發布版本程式及實測為依據，舊需求文件僅作背景，不直接複製其功能承諾。

建立內容對照表，記錄網站段落、程式／測試來源、發布版本、驗證日期。主要依據為 `src/ui/views/panel.ts`、`src/chat/`、`src/environment/`、`src/drive/`、`docs/gcp-setup.md` 與實際酒館流程。

## 7. FAQ 與資料說明

### 首批 FAQ

- 安裝後找不到 TavernRoamer 面板。
- Google Client ID 填入後無法連線。
- origin 不符、測試使用者未加入、API 未啟用。
- 授權完成後顯示 `popup_closed`。
- token 過期或撤銷權限後如何重新連線。
- 另一台裝置看不到備份：核對帳號、Cloud 專案／Client ID、來源與備份完成狀態。
- 拉取時缺少角色卡或環境素材。
- 還原是否覆蓋目前聊天或共用素材。
- 手動搬入 Drive 的檔案為什麼找不到。
- 如何更新、停用、自動同步設定與卸載；停用／卸載不應被描述為會自動刪除 Drive 資料。

`popup_closed` 頁面先列可能原因與診斷步驟，不能一律判定為 COOP 問題。若確認是 server header 問題，區分本機與雲端處理方式，優先使用部署平台或酒館支援的設定，附重啟與回復說明。

資料頁說明備份位置、加密現況、授權撤銷方式與覆蓋前備份範圍；不得把備份機制描述成所有情況均可完整回復。截圖與錯誤範例使用測試帳號與虛構聊天，遮蔽 email、Client ID、token 和私人網址。

## 8. 技術與視覺方案

建議在同一倉庫新增獨立 `website/`，使用 Astro + TypeScript + Markdown／MDX，輸出靜態網站；這是實作預設，建立時再核對工具版本。網站有獨立 package scripts，不改動現有腳本打包與 `dist/` 產物。

```text
website/
  src/pages/           # 頁面路由
  src/content/        # 教學、FAQ、版本紀錄
  src/components/     # 步驟、提示、複製按鈕、網址助手
  src/layouts/        # 首頁與文件頁版型
  src/styles/         # 全站視覺與響應式樣式
  public/images/      # 已遮蔽敏感資訊的截圖
  package.json
```

- 內容優先輸出靜態 HTML；只有複製、選單、網址助手等操作需要 JavaScript。
- 主題採酒館／旅途意象，維持清楚的文件閱讀體驗；不用大面積動畫阻擋安裝內容。
- 文件桌面版有章節目錄；手機版有可展開目錄與足夠大的操作區。
- 所有圖片有替代文字，步驟具有語意順序、可見焦點與足夠對比。
- 每頁具有獨立 title、description、社群分享資訊；canonical 與 sitemap 在正式網址確定後設定。
- 安裝連結、版本、GitHub 與問題回報地址集中管理，避免各頁不同步。
- 靜態主機與網域尚未選定；建置需能在網域根目錄及子路徑部署。

## 10. 驗證策略

優先測試影響安裝成功的行為，不為靜態文案編寫重複測試。

| 類型 | 必要驗證 |
|---|---|
| 網址助手 | 路徑移除、port 保留、localhost 差異、多筆去重、缺 scheme、無效／含帳密／非 HTTP(S) 輸入 |
| 頁面操作 | 複製成功與失敗提示、手機導覽、章節跳轉、鍵盤焦點 |
| 安裝連結 | 產物存在、匯入方式實測、網站顯示版本一致 |
| OAuth 教學 | 新專案設定、本機／雲端 origins、授權成功、常見錯誤排解 |
| 跨裝置流程 | 同帳號及同 Client 設定，來源備份、目標找到聊天、角色缺失分支、拉取後內容核對 |

若缺少測試酒館或帳號，完成可獨立驗證的部分並明列待測項；未實測不能宣稱完整驗收通過。
