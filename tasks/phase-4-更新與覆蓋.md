# Phase 4：檢查更新與下載覆蓋

> 規格對應：[開發手冊-v2.md](../開發手冊-v2.md) 第十、十一、十二章、14.3
> 目標：M2 —— 版本選擇、成套還原、覆蓋前備份/還原全部到位

## 任務

### 檢查更新（第十章）
- [ ] `CHAT_CHANGED` 自動檢查 chat item 是否有新版（非阻斷 toast + 面板標記）
- [ ] `[檢查完整環境更新]`：掃描該 chat_id（由聊天檔名時間戳導出）全部 item 目錄，組版本資料
- [ ] 版本選擇區 UI（14.3）：item / 預設版本 / 上傳時間（本地時區）/ 來源裝置 / 可用版本數 / 改選下拉 / 更新開關

### 各 item 還原器（11.2 表格逐條實作）
- [ ] **chat**：同 chat_id 存在 → 就地覆寫（沿用 Phase 2）；不存在 → 確保角色卡存在並選中 → `importRawChat` 建立；建立後以新聊天檔名重新導出 `chat_id`，並寫入 `_drive_sync`
- [ ] **character**：`createOrReplaceCharacter()` 同名覆蓋
- [ ] **world**：逐本同名覆蓋 → rebind 聊天/角色卡綁定；全域開啟清單只列出供勾選，不自動改
- [ ] **persona**：`createOrReplacePersona()` 同名覆蓋
- [ ] **preset**：`createOrReplacePreset()` 同名覆蓋 + 載入；覆蓋提示列出將被覆蓋的預設名
- [ ] **regex**：全域正則同名覆蓋、其餘保留，合併後 `replaceTavernRegexes({type:'global'})`

### 覆蓋前備份（第十二章）
- [ ] 覆蓋前打包「將被覆蓋的 item 本地現狀」上傳 `_pre_restore/{timestamp}/`（取代 Phase 2 的最簡版）
- [ ] 離線時中止覆蓋並提示（不允許無備份的覆蓋）
- [ ] `_pre_restore/` 保留最近 3 筆自動清舊
- [ ] `[還原覆蓋前備份]`：列出備份 → 選擇 → 走相同還原器還原

### 覆蓋流程（11.3、11.4）
- [ ] 警告對話框：固定文案 + 動態列出將被覆蓋的預設名/世界書名 + 「本地有未上傳變更」加強警告
- [ ] 依勾選逐 item 還原，彙總報告，完成後提示重新整理頁面

## 驗收標準（= M2 驗收）

### 自動（CI，對 mock Drive）
1. 還原順序：斷言固定為 character → world → persona → preset → regex → chat
2. regex 合併：同名覆蓋、本地多出的保留（fixture 交叉組合）
3. 版本選擇狀態機：各 item 改選版本/設不更新 → 產出的還原計畫正確；「不更新」的 item 絕不出現在計畫中
4. 覆蓋前備份內容 = 即將被覆蓋的 item 集合（勾什麼備什麼）
5. 離線（mock 全部請求失敗）→ 覆蓋中止、本地 mutation 呼叫數為 0
6. `_pre_restore/` 保留 3 筆清舊邏輯

### 自動（一鍵自檢，真實酒館 + 真實 Drive）
7. **核心來回案例**：備份完整環境 → 故意改動本地（改卡、刪一條全域正則、換預設參數）→ 全項還原 → 逐 item deep-equal 備份時狀態
8. 不刪除原則：本地建一張備份外的角色卡 → 還原 → 斷言該卡仍存在
9. chat 就地覆寫：同 chat_id（來源為聊天檔名時間戳）還原後訊息陣列與雲端版本 deep-equal，且本地聊天檔案數不增加
10. 覆蓋前備份還原：執行覆蓋 → `[還原覆蓋前備份]` → 斷言回到覆蓋前狀態（含聊天內容）
11. 警告對話框資料層斷言：將被覆蓋的預設名/世界書名清單內容正確（渲染前的資料即可斷言）

### 手動（無法自動的理由附註）
12. A 實機備份 → B 實機還原 → 發一句訊息確認 AI input 等效（*跨裝置實機 + AI 行為語意判讀*）
13. 混搭版本操作一輪：chat 最新、character 舊版、world 不更新（*透過真實 UI 操作驗流程，資料邏輯已由 #3 覆蓋*）
14. 警告對話框的視覺呈現與文案（*UI 視覺*）

## 風險備註
- 還原順序固定為：character → world → persona → preset → regex → chat（聊天最後，因 importRawChat 依賴角色卡已存在且被選中）
- preset 同名覆蓋的處理方式取決於客戶對第十六章 #4 的回答，開工前確認
